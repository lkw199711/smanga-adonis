## 图片特性

✅ **真实有效的 JPEG 文件**
- 格式: JPEG baseline, 8-bit
- 尺寸: 800x1200 像素（页面）, 800x600 像素（章节封面）
- 大小: 约 19-29 KB
- 内容: 模拟漫画分格布局，包含文字标注

✅ **漫画封面**
- 彩色渐变背景（随机颜色）
- 包含漫画名称和 "COVER" 字样

✅ **章节页面**
- 白色背景
- 模拟漫画分格（3-6 个格子）
- 包含漫画名、章节名、页码信息

## 使用说明

### 1. 配置扫描路径

在 smanga 系统中添加扫描路径时,指向:
```
/Users/ext.liangkaiwen8/dev/smanga/smanga-adonis/test-manga-data
```

或者指向具体的漫画库:
```
/Users/ext.liangkaiwen8/dev/smanga/smanga-adonis/test-manga-data/漫画库1
```

### 2. 扫描功能测试

这些测试数据可以用于测试以下功能:

- ✅ 漫画目录扫描
- ✅ 章节识别
- ✅ 图片文件识别
- ✅ 封面图片提取
- ✅ 多级目录结构解析

### 3. 目录层级说明

```
路径根目录
  └─ 漫画库 (可选的分组目录)
      └─ 漫画文件夹 (包含 cover.jpg)
          └─ 章节文件夹 (包含 cover.jpg 和多张图片)
              ├─ cover.jpg (章节封面)
              ├─ 第X话_第1页.jpg
              ├─ 第X话_第2页.jpg
              └─ ...
```

## 图片说明

所有生成的图片都是最小的有效 JPEG 文件 (1x1 像素,约 200 字节),仅用于测试扫描功能,不包含实际漫画内容。

## 清理

如需删除测试数据:
```bash
rm -rf /Users/ext.liangkaiwen8/dev/smanga/smanga-adonis/test-manga-data
```

## 重新生成

如需重新生成测试数据:
```bash
cd /Users/ext.liangkaiwen8/dev/smanga/smanga-adonis
node generate-test-manga.mjs
```

## 技术实现

- 使用 Node.js + Sharp 库生成真实 JPEG 图片
- 通过 SVG 矢量图形转换为 JPEG
- 模拟漫画页面布局（分格、边框、文字）
- 随机颜色生成器创建多样化封面
